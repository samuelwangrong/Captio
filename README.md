# Captio

> Accurate, beautiful captions for YouTube — Chrome extension + web app.

## What is Captio?

Captio replaces YouTube's auto-generated captions with Whisper-powered transcription that's more accurate across accents, technical language, and fast speech. The Chrome extension overlays improved captions directly on YouTube, with customizable styling. The web app adds language learning features, vocabulary saving, and a regional content explorer.

## MVP Scope

- Chrome extension: improved caption accuracy + styling overlay
- Web app: caption export, language learning mode
